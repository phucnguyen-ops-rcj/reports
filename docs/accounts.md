# Account Aliases

Use these aliases for `/get-balance` and `/run-transfer` requests.

## Exchanges

- `fr`

`binf` / Binance futures:

- `fr`

`byb` / Bybit:

- `fr`

## Notes

- Use `main` for main accounts where supported.
- For `kc` sub-account transfer modes, pass `sub_account_name`.
- For `kcf` futures transfer modes, pass `sub_account_name` and use the correct `market` when required.
